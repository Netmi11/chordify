# ChordShift for Tab4U

זהו תוסף Chrome/Edge ניסיוני לשינוי שמות אקורדים בדפי Tab4U.

## התקנה מקומית

1. פתחו את `chrome://extensions` או `edge://extensions`.
2. הפעילו **Developer mode**.
3. בחרו **Load unpacked**.
4. בחרו את תיקיית `extension` מתוך הפרויקט.
5. פתחו או רעננו דף שיר ב־Tab4U.

התוסף מזהה שורות שבהן מופיעים אקורדים בלבד, עוטף כל אקורד מבלי לשנות את הרווחים, ומוסיף סרגל צף עם שינוי חצי־טון, איפוס ובחירה בין דיאזים לבמולים.

## קיצורי דרך

`[` מוריד חצי טון ו־`]` מעלה חצי טון.

## גבולות הגרסה

הגרסה הראשונה מזהה אקורדים בשורות נפרדות או בשורות שמכילות אקורדים בלבד. היא אינה מנסה לנחש אקורדים מתוך משפטי מילים, ואינה משנה צורות אצבוע או כיוון מיתרים. אם מבנה דף מסוים לא מזוהה, הדף המקורי נשאר ללא שינוי.
