# Tab4U parser fixtures

ה־fixtures כאן הם דוגמאות מינימליות, המבוססות על שתי צורות תצוגה שנצפו בדפי שירי Tab4U: מבנה טבלאי שבו כל שורה מחזיקה תא אקורדים ותא מילים, ומבנה fallback שבו התוכן מחולק באמצעות תגיות `<br>`.

| קובץ | מקור וריאציית המבנה | מה הבדיקה מאמתת |
|---|---|---|
| `tab4u-table-variant.html` | וריאציה טבלאית מקבילה למבנה שנצפה בדף הדוגמה שסיפק המשתמש: כותרת סעיף, שורת אקורדים, שורת מילים, רווחים פנימיים ושורה ריקה. | זיהוי `songContentTPL`, שמירת כותרת סעיף, שמירת רווחים בין אקורדים, שמירת רווחים בתחילת/סוף תא, שמירת שורה ריקה ומספר שורות. |
| `tab4u-br-variant.html` | וריאציית fallback מינימלית שבה אזור השיר הוא טקסט רציף המופרד ב־`<br>`, כולל `<br><br>` לשורה ריקה. | מעבר למסלול fallback, שמירת סדר השורות, שמירת השורה הריקה והחזרת מספר שורות תקין גם ללא טבלה. |

הקבצים אינם עותק מלא של שיר ואינם משמשים כמקור תוכן למשתמש. הם fixtures לבדיקת מבנה HTML בלבד, כדי למנוע תלות בכך שאתר חיצוני יהיה זמין בזמן הרצת הבדיקות.
