# מאיר בנאי — מקורות מאומתים

אינדקס האמן אומת בדפדפן. נמצאו עמודי שיר מדויקים עבור: לך אלי תשוקתי (4862), כמה אהבה (3662), גשם (3675), שירו של שפשף (1878), וביניהם (1883), מחפש את הכיוון (4927), דומינו (743; עמוד Tab4U מציין גם את ארקדי דוכין), לב סדוק (1881), אליה (1880), מנגינת הנדודים (3677), והגשם הראשון (3676).

הפריטים „רואים רחוק רואים שקוף”, „אגדת דשא”, „הצבעים משתנים”, „אולי היום” ו„שמע קולי” לא הופיעו כעמודי שיר מדויקים בקישורי האינדקס שנבדק. „שמע קולי” הופיע רק כקישור אלבום. אין לייבא אותם בלי אימות עמוד שיר מתאים.
