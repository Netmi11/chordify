# רשימות הצעה לאישור — הרחבת ספריית ChordShift

המסמך מציע **80 שירים** בשש קבוצות. בשלב זה אין ייבוא: לאחר אישור, כל שיר יעבור איתור של דף Tab4U מדויק, אימות תוכן, שמירת snapshot, בדיקת כפילות מול הספרייה ו־dry-run לפני הוספה. השירים נבחרו מתוך קטלוגים ורשימות שירים ציבוריות של האמנים, במיקוד על שירים מוכרים ושימושיים לנגינה. ## אישור

אפשר לאשר את כל הרשימה באמצעות: **„מאשר הכול”**. אם יש שיר שברצונך להחליף, כתוב את שם האמן ומספר השיר או את השם המדויק של השיר החלופי. לאחר האישור לא אחליף מקור או כותרת בלי לתעד זאת מולך.
