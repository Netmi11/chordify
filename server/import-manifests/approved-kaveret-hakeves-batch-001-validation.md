הפער בין שורות משמעותיות ב־dry-run לבין שורות במסד נובע משורות ריקות/מבניות שנשמרות כדי לשמור את מבנה השיר ואת מיקום האקורדים. ה־dry-run הנכון, עם ה־library ID הפרטי המדויק, החזיר 3 פריטים `readyToAdd` ו־0 כפילויות. לא בוצעה דריסה של רשומות קיימות.

## אימות מסד נתונים

אימות SQL מצא רשומה אחת לכל אחד משלושת מקורות Tab4U. לאחר ה־commit, הספרייה הפרטית מכילה **240 שירים**, **240 מקורות ייחודיים** ו־**22,239 שורות**. לפני תת־האצווה היו 237 שירים ו־21,998 שורות, כך שהתווספו 3 שירים ו־241 שורות מסד.

## בדיקות איכות

עברו בהצלחה 10 קובצי Vitest ובהם **49 בדיקות**, TypeScript ללא שגיאות ו־build ייצור. ה־build מציג את האזהרות הלא־חוסמות הקיימות: נכס רקע שנפתר בזמן ריצה ואזהרת chunk מעל 500KB.

## מקורות שטרם יובאו

שאר המועמדים ברשימות כוורת והכבש השישה־עשר עדיין אינם מיובאים. לכל אחד מהם נדרש אימות דפדפן ושמירת snapshot נפרדת; תוצאות חיפוש או כתובת שלא נפתחה ואומתה אינן מספיקות לייבוא. שלושת המועמדים „ילד מזדקן”, „האיש הכי מהיר” ו„התמנון האיטר” נשארים ללא URL מדויק מאומת, ללא ניחוש או החלפה.
